# 1.2.3 — Date formatter

## What was asked

A single static method that turns an ISO-8601 timestamp string into a display date
(`d MMM yyyy`, e.g. `15 Sep 2026`), returning an empty string instead of throwing for null, empty,
or unparseable input.

## What changed

- `lib/core/utils/date_formatter.dart` — new. `DateFormatter.format(String? isoDate)`: returns `''`
  for `null` or an empty string, uses `DateTime.tryParse` so unparseable input also returns `''`
  instead of throwing, and otherwise converts the parsed date to local time and formats it with
  `intl`'s `DateFormat('d MMM yyyy')`.

## What was tested

- `test/core/utils/date_formatter_test.dart`, written first and confirmed failing (no
  `date_formatter.dart` existed yet) before the file above was created:
  - a valid ISO-8601 timestamp formats correctly — the expected string is built from the same
    `DateTime.parse(...).toLocal()` + `DateFormat` steps the formatter uses, not a hardcoded date,
    so the test is not tied to one timezone.
  - `null`, `''`, and `'not a date'` each return `''`.
- `flutter analyze` — no issues found.
- `flutter test` — full suite passing.

## Anything left open

Nothing for this subtask. `DateFormatter` is not yet referenced anywhere in `lib/` — it gets wired
in where a published date is displayed (the article card in 2.3.3, and the details screen in
3.1.2).
